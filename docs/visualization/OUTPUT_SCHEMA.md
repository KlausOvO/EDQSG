# 图形输出结构

```text
output/sqlserver/
├── edqsg_sqlserver_report.json
├── edqsg_sqlserver_report.md
├── edqsg_sqlserver_report.html
├── edqsg_dashboard.html
└── figures/
    ├── figure_manifest.json
    ├── fig01_indicator_scores.png
    ├── fig01_indicator_scores.svg
    └── ...
```

`figure_manifest.json`记录图号、标题、解释和所有输出文件，可用于论文图表目录和自动化归档。
