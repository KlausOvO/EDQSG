# EDQSG-U1.1 建设性修订与实现报告

## 1. 本次交付目标

本次修订保留EDQSG“数据质量结果域Q—结构治理成因域S—多源证据—非补偿底线—Q-S根因—治理复评”的主线，重点修复文档与自动分析代码之间的可验证性缺口，并建立可重复的航空器材管理双域基准。

## 2. 模型文档修订

- 明确分开报告指标得分、可信度、未知度和冲突度，避免把“证据不足”直接解释为“质量差”；
- 建立物理外键与逻辑外键双轨关系，防止删除物理约束后同时失去DQ6检测入口；
- 将SG2从宽表/堆表代理扩展为记录粒度、原子性、多值字段、字段上限和表职责规则；
- 将SG7从“权威表是否存在”扩展为权威引用、孤儿和复制属性冲突；
- 将SG8细化为审计、版本/时态、变更、退出和互操作字段控制；
- 增加单因素确定性敏感性分析，与蒙特卡洛稳健性形成互补；
- 把验证真值扩展为数据缺陷、结构缺陷、证据属性和Q-S传播路径四层。

修订后的正式文档为《EDQSG-U1.1模型方案_建设性修订版》DOCX/PDF。

## 3. 代码调整

### SQL Server规则与证据

- `sqlserver/config.py`：新增`LogicalForeignKeyRule`、`TableModelRule`扩展、`MasterDataConsistencyRule`、`LifecycleControlRule`、`SupplementalEvidenceRule`；
- `sqlserver/profiler.py`：新增逻辑外键孤儿剖析、主数据引用及复制属性冲突剖析；
- `sqlserver/analyzer.py`：将逻辑关系映射至DQ6/SG4，将主数据冲突映射至DQ2/DQ5/DQ6/SG7，将显式表模型规则映射至SG2，将生命周期规则映射至SG8，并允许过程/专家证据进入自动流水线；
- 底线触发器可使用逻辑外键和主数据一致性结果。

### 稳健性

- `robustness.py`：修复冗余风险值扰动后风险等级未重算问题；
- 新增`DeterministicSensitivityAnalyzer`；
- `models.py`、`core.py`、`__init__.py`：新增`SensitivityCase`、`SensitivityReport`和`model.sensitivity(...)`入口。

## 4. AeroMRO-EDQSG验证数据库

基准使用SQL Server 2019+，包含：

- 航空器/机型、ATA章节、制造商、供应商、器材主数据、适用性和替代关系；
- 仓库、库位、器材实例、库存余额和库存事务；
- 采购、收货、证书和检验；
- 工单、装拆、使用快照、寿命控制、送修和报废；
- 质量规则、运行、问题和注入清单实验表。

数据规模：

| 规模 | 器材主数据 | 器材实例 | 采购单 | 用途 |
|---|---:|---:|---:|---|
| small | 80 | 300 | 30 | 单元测试和演示 |
| medium | 800 | 8000 | 500 | 论文主实验 |
| large | 5000 | 100000 | 5000 | 扩展性实验 |

基准提供14个单缺陷脚本、3组结构传播负载和`ground_truth/defect_catalog.csv`。每个场景必须从干净数据库副本独立执行。

## 6. 尚未完成的真实环境验证

当前交付环境没有可用SQL Server实例，因此未实际执行建库脚本、污染脚本，也未完成真实数据库端查询兼容性、执行计划、性能和分值校准。正式论文结论必须在SQL Server 2019+测试库或只读副本完成以下补验：

1. 建库与所有约束/扩展属性的兼容性；
2. full模式查询负载和超时；
3. 单缺陷分数单调性及识别F1；
4. 传播负载前后Q、S、根因贡献和底线变化；
5. 与真实专家、日志、工单和治理复评证据的一致性。

## 7. 推荐运行顺序

1. 执行`schema/00_create_database.sql`、`schema/01_clean_schema.sql`和`data/02_seed_clean_small.sql`；
2. 使用`config/sqlserver/aeromro_benchmark.yaml`评价干净基线；
3. 为每个场景复制干净库，单独执行一个`scenarios/*.sql`并复评；
4. 结构传播实验先评S，再执行对应`workload/*.sql`，最后复评Q和根因；
5. 对污染率1%、3%、5%、10%、20%和多个随机种子重复；
6. 运行M1—M5消融、±10%/±20%确定性敏感性及蒙特卡洛稳健性；
7. 选1—2个高根因问题进行真实治理并重新采证复评。
