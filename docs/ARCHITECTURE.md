# EDQSG 0.2.0 架构说明

## 1. 计算链

```text
原始数据/DDL/标准/日志/专家判断
            ↓
       Evidence对象
            ↓
可靠性计算 → 可靠性折扣 → ER递归组合
            ↓
指标等级分布、未知度、冲突度、得分、可信度
            ↓
       Q域与S域聚合
            ↓
几何综合、平衡度、综合可信度、底线约束
            ↓
三源Q-S耦合校准 → 根因贡献度
            ↓
冗余风险 + 治理模板 → 治理任务及优先级
            ↓
整改后重新评价 → 复评比较 → 耦合反馈更新
```

## 2. 关键设计决策

### 证据不再等同于分数

证据提供五个确定等级的支持度和未知度。低可靠性支持质量被转入未知状态，而不是简单降低分数。

### 高冲突不静默平均

证据冲突超过阈值时，指标会标记为需要复核。极端冲突采用保守组合，避免分母 `1-K` 接近0造成数值失真。

### 底线约束按真实触发执行

没有触发规则时，最终分数等于初始综合分数。一级、二级底线及重大惩罚通过 `BottomLineTrigger` 明确输入。

### 耦合矩阵不是单一专家矩阵

`CouplingCalibrationInput` 分别记录规范、专家和历史数据强度及可信度，系统按可用来源重新归一化权重。

### 核心模型无随机输入

随机数据仅存在于 `simulation.py`。正式模型不会自行生成指标、权重、耦合关系或治理任务参数。

## 0.4.0 可视化输出层

```text
AssessmentReport + DatabaseMetadata + DatabaseProfile
                    │
                    ├── PaperFigureGenerator
                    │     ├── 评价结果图
                    │     ├── 证据与耦合图
                    │     ├── 根因与治理决策图
                    │     ├── 数据库描述统计图
                    │     └── 稳健性图
                    │
                    └── DashboardExporter
                          └── edqsg_dashboard.html
```

可视化模块不参与模型评分，只读取已完成的评价结果，因此不会因图形参数改变EDQSG结论。Matplotlib被设计为可选依赖，关闭`visualization.enabled`时，SQL Server自动评价可在不安装Matplotlib的环境运行。

## U1.2关系控制层

SQL Server流水线在元数据采集与证据构建之间增加预期关系控制剖析：匹配可信物理外键、读取替代控制和受控例外、执行孤儿检测，并分别输出SG3控制有效度、SG4关系语义和DQ6运行结果。
