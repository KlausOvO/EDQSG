# 安全与生产运行要求

1. 使用专用只读账户，遵循最小权限；
2. 密码通过环境变量或密钥管理系统提供，不写入YAML、JSON和源码；
3. 输出报告可能包含表名、字段名、规则说明和少量统计结果，应按内部数据治理材料管理；
4. 当前实现不会导出原始业务记录，但自定义规则和错误消息可能暴露结构信息；
5. `full`模式可能产生较大查询负载，应先在测试库、只读副本或备库运行；
6. 不要将不可信用户输入直接写入 `custom_sql_rules`；
7. 首次运行应由 DBA 审查查询计划和超时设置；
8. 如启用 `read_uncommitted`，结果可能读取未提交数据，仅适合低影响摸底，不适合正式治理验收。
