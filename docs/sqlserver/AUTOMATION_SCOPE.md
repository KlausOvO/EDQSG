# 自动化能力与证据可信度

SQL Server适配器能够自动产生结构证据和部分数据证据，但数据库本身无法完整表达业务语义。

## 高自动化、高可信度

- 表字段、类型、主键、外键、索引、约束；
- 已配置规则的违规率；
- 业务键重复率；
- 已声明外键孤儿率；
- 全量扫描得到的统计结果。

## 自动化但需要降权

- 通用空值率（未区分必填与可选）；
- 根据字段名称推断的冗余候选；
- 根据表结构相似度推断的表冗余；
- 审计字段名称匹配；
- 宽表和堆表风险。

## 需要人工或补充数据

- 字段业务定义是否准确；
- 合理冗余与不合理冗余；
- 主数据权威边界；
- 结构缺陷与质量问题的历史数据强度；
- 治理成本、责任主体和组织协同。
